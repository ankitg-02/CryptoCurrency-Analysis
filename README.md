#Overview:
This Flask-based web application provides cryptocurrency price predictions using machine learning. It features user authentication, interactive visualizations, and real-time price predictions.

#Features:
User authentication (register/login)
Real-time cryptocurrency price predictions
Interactive data visualizations using Plotly
Model training and evaluation
Historical price analysis
Volatility tracking

#Tech Stack:
Python 3.8+
Flask web framework
SQLAlchemy for database management
CatBoost for machine learning
Plotly for data visualization
SQLite for local development

#Installation:
Clone the repository
Create and activate virtual environment
Install dependencies
Set up environment variables
